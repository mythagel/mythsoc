# RULES for agents

1. Be terse and technical in reasoning and communication
2. Do not attempt to compute yourself - write and use python or verilog tools to do calculations - store in tools/
    - "Let me (re)compute.." NO! Write / use a tool
    - DO NOT CALCULATE BIT POSITIONS. Write / use a tool!
    - trying to determine set bits in a hex value? - use a python tool
    - Convert hex to decimal or vis-versa? - use a python tool
    - Unclear on verilog construct? - write small program and compile with iverilog
3. Specifications in specs/ are the source of truth, NOT your memory.
    - No planning until you have read the specs, DO NOT RELY ON MEMORY
    - Ensure tables are accurate - use PDF skill or convert to image and read directly.
4. Keep notes on progress in notes/ and re-read them after following step 6.
5. No webfetch
6. As proof of having read this, as the FIRST thing you do at session start, reiterate these rules.
